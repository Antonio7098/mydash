# Dashboard Shell

Use these classes:

```html
<div class="mydash-shell">
  <header class="mydash-shell__header">...</header>
  <main class="mydash-shell__main">
    <div class="mydash-grid mydash-grid--metrics">...</div>
  </main>
</div>
```

The layout supplies structure only. Artefacts own their information
architecture and content.
